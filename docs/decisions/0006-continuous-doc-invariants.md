# 0006：持续文档检查只守护可机械判断的不变量

2026-11-02，按项目所有者本轮自主开发授权，由总审核决定实施。

[0034](../specs/0034-ci-guest-tests-and-status-archive.md) 把状态页大小和规格索引数量定义为交付条件，同时把该阶段的检查脚本限定为一次性验证。Issue #177 提议把更多条款变成持续门禁；其中部分是历史迁移动作，部分需要语义判断，全仓链接扫描也扩大了原 AC8.2 的范围。

本阶段只把 STATUS 字节上限和索引数据行数量接入默认 CTest。它们不需要编译产品、运行 Guest、模型或扫描整个工作区；用小型临时树控制证明合法边界通过、越界和漏行失败。现有 workflow 继续执行默认套件一次，不为展示输出增加单独复验步骤。

索引检查只计规定形态的数据行，不宣称链接、编号对应、唯一性或状态正确。其余语义对齐继续独立文档审核；0034 的历史归档、一次性交付要求不改为每次提交都必须重新执行的实验。链接卫生没有在本阶段扩大范围。

以 [0042](../specs/0042-continuous-doc-invariants.md) 定义后续持续执行契约。0034 的原阶段结论和 non-goals 保留，不能把它当作已经允许持久化脚本的依据。候选代码最初按原两条 AC 起草；总审在独立审核前发现范围缺口，先补齐本决定与规格，再冻结验收，不把候选编写顺序伪称为规格先行。
