# 决策0009：通过现有MCP读取显式知识图

日期：2026-11-03。状态：采用。项目所有者在0044完成后授权继续发布、接入现有MCP及真实使用验收，沿既有自主设计授权推进；前端仍由所有者确定。

0044已有显式概念、别名和带块出处的命题。新增两个只读MCP工具，让Agent在同一个客户端里查询概念并按来源身份读原文。无记录不表示用户不懂；工具不自动推理，也不替Agent生成回答。

首版继续每次重建内存图并观察前后来源，不引入缓存、分页或多跳推理。沿0044的前20项与完整总数；Agent可取具名块全文。当前CLI限制与未来交互改进分别记录，不扩为图形界面或图数据库项目。
