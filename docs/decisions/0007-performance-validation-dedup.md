# 0007：让性能矩阵同时承担预算与确定性验收

2026-11-02，按项目所有者本轮自主开发授权，由总审核决定实施。

[0040](../specs/0040-4095-file-performance.md)的完整矩阵与独立4095复轮，加上[0036 R8](../specs/0036-yanfs-multi-block-directory.md#0036-r8大容量查询性能)，在默认套件中重复启动相同固定语料。删除旧入口会丢失1023/2047档生产mkfs与filler建盘验证，直接减少复轮则无法证明同输入同构建的计步一致。

统一执行27项首轮矩阵和9项4095独立复轮。先以实际生产工具生成63/1023/2047镜像，与独立编码器逐字节比较；对应大容量矩阵使用真实生成物。每次复轮重新复制原夹具，完整核对输出、镜像与状态，再比较两轮全状态和退出码。原有步数、栈、arena、输入身份和失败分类保持。

现有独立runner与oracle已经承载这些职责，只在两者及CMake适配，不增加跨CTest缓存或通用调度器。旧独立CLI仍可显式复现，默认注册合并为一个实际入口；[0043](../specs/0043-performance-validation-dedup.md)定义新增选项、记录与控制。阶段旧结论保留，统计执行次数不冒充实测耗时节省。前端不在本决定范围内。
