# 0008：用原文支持概念与命题关系

2026-11-02，项目所有者认可图模型并授权设计、由dsh编码和验收。

笔记中的知识按项目所有者声明视为已理解知识。文件链接只能表达引用，不能表达具体命题及其适用条件。Agent需要读取记录中的具体关系和原文依据，从这些知识解释新内容；未记录不能推断为不懂。

采用有类型的有向属性多重图：概念有显式ID、名称和别名；每条显式关系是独立命题记录，附完整具名块地址、物理位置及来源身份。条件和解释保留在原文块，不根据关系路径推导用户已知内容。全图允许环和多重边。自动抽取、相似度和模型推断不作为用户声明的关系写入图。

纯文本仍是唯一事实来源。正文新增显式的`@kg`行，已有元数据头和块语法保持；Host构建可重建内存索引，借用现有只读镜像适配。先交付C服务和JSON命令接口，Agent可配合已有MCP块读取取得全文；MCP新增工具、Guest图命令、持久缓存和图形前端另行设计。首版不引入图数据库或生成模型。

语义依据：[IHMC命题](https://cmap.ihmc.us/docs/proposition.php)；表示模型参考[Apache TinkerPop属性图](https://tinkerpop.apache.org/docs/current/reference/#the-graph-structure)。使用属性图不要求依赖该软件。
