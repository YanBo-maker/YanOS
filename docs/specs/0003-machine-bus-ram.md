# 0003：Machine、Bus 与 RAM

阶段 0 的实现规格。CPU 提案中的后续指令、CSR 和设备设计仍待对应阶段审查。

## INTENTION

建立可供 CPU 访问的机器内存。先用 Host 测试程序装入字节、读回数据和触发错误，验证 Guest 地址如何定位到 RAM。

当前范围包括 RAM 生命周期、小端读写、Bus 地址映射及 Machine 组装。CPU 状态、取指、设备寄存器和文件读取属于后续任务。

## SPEC

### 模块与接口

公开接口位于 `include/yan/`，返回 `YanStatus` 表示成功或具体错误。

| 模块 | 状态与操作 |
| --- | --- |
| `YanRam` | 字节缓冲区与容量；初始化、释放、清零、按偏移读写 |
| `YanBus` | 借用 RAM 指针，记录映射起点；按 Guest 地址读写 |
| `YanMachine` | 拥有 RAM 与 Bus；初始化、释放、复位、装入内存镜像 |

RAM 与 Machine 使用前零初始化，例如 `YanMachine machine = {0};`。活跃对象不能按值复制或重复初始化，重复初始化返回状态错误并保留原内容。释放可以重复调用，释放后的对象可以重新初始化。

Bus 不拥有 RAM，其有效期由 RAM 所有者保证。映射成功后 RAM 容量保持不变。Machine 释放时先解除 Bus 引用，再释放 RAM。

### RAM

- 初始化接受非零容量，分配失败返回内存不足。新 RAM 全部为零。
- 偏移类型为 `size_t`；宽度仅接受 1、2、4 字节。
- 多字节数据采用小端格式，读取结果使用 `uint32_t`，高位补零；写入使用值的低 8、16 或 32 位。
- RAM 作为字节存储允许任意偏移；Guest 地址的对齐由 Bus 检查。
- 整个访问必须落在缓冲区内。检查避免 `offset + width` 溢出。
- 读取失败保留输出参数，写入失败保留 RAM。

### Bus

阶段 0 只映射一块 RAM。初始化接受映射起点，检查整个区域位于 32 位地址空间，非法映射保留原 Bus。Machine 默认映射为 `0x80000000～0x81FFFFFF`，容量 32 MiB。

`yan_bus_read` 和 `yan_bus_write` 接受 Guest 地址与宽度，返回包含状态、地址、宽度和读写种类的 `YanBusResult`。读结果通过输出参数返回。

检查顺序为参数和对象状态、宽度、自然对齐、起始地址映射、完整访问范围。16 位访问要求地址为 2 的倍数，32 位访问要求地址为 4 的倍数。

Guest 地址小于映射起点或位于区域之外时返回未映射。起始地址在区域中、访问末尾超过区域时返回越界。32 位地址顶部的访问也按完整范围检查。错误不会修改 RAM 或读输出参数。

本阶段 Bus 处理数据读写。取指种类及执行权限在 CPU 取指规格中加入；Host 错误状态暂不转换为 Guest 异常。

### Machine

- `yan_machine_init` 创建并映射默认 32 MiB RAM。
- `yan_machine_init_with(machine, ram_base, ram_size)` 按显式几何组装，供需要选择 RAM 窗口的工具使用（例如 `yan_run --base/--ram`）；几何记录在 `YanMachine` 内，供完整性检查与复位使用。
- 几何在组装时校验，且校验先于分配：`ram_size` 为 0，或窗口与任一设备窗口（CLINT `0x02000000`、PLIC `0x0c000000`、UART `0x10000000`、transport `0x10001000`）重叠，都返回 `YAN_INVALID_ARGUMENT`；窗口越过 32 位地址空间返回 `YAN_OUT_OF_BOUNDS`（由 `yan_bus_init` 判定）。被拒的调用不分配内存，也不改变对象。之所以拒绝重叠：Bus 的解码顺序让设备优先，重叠会让该段 RAM 不可见。
- 几何一旦组装即视为该机器的不变量：`yan_machine_reset` 把 CPU 复位到这台机器自己的 `ram_base`，不使用编译期常量。完整性检查因此只能校验"记录的几何与活字段是否一致"，查不出把记录与字段一并改掉的自洽篡改。
- `yan_machine_reset` 清零 RAM，保留映射和已分配的缓冲区。本阶段没有 CPU。
- `yan_machine_load_image` 将调用者提供的 Host 字节缓冲区复制到 RAM 起点，保留镜像之后的原内容。
- 空镜像是有效操作，可使用空指针。非空镜像要求有效源缓冲区；超长镜像在复制前拒绝。
- 镜像源由调用者保证可读且长度有效。装载允许源与目标重叠。
- 冷启动顺序为初始化或复位，再装载有效镜像。单独装载失败保留已有内存。

未来 CPU 复位可以保留内存；这里的 Machine 复位表示整机内存清零，两种操作各自保留明确语义。

### 验收用例

- RAM：零初始化、全部宽度、小端组合、任意偏移、低位截取、首尾边界、非法宽度、`SIZE_MAX` 偏移和失败原子性。
- Bus：地址转换、自然对齐、未映射、跨区域末尾、32 位地址空间顶部、非法映射和完整错误信息。
- Machine：默认映射、镜像读回、空镜像、超长镜像拒绝、复位清零、对象重复使用和独立实例。
- Release 构建保持测试检查有效；启用地址与未定义行为检测检查内存访问。
