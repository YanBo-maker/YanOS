# 0007：条件分支与跳转

单步中的 Guest 错误处理已由 [0009：M-mode 同步异常](0009-guest-traps.md) 更新；本文件保留对应阶段的指令规格。

## INTENTION

在整数计算基础上实现控制转移，让 CPU 根据条件选择后续指令，并保存函数调用的返回地址。新增 BEQ、BNE、BLT、BGE、BLTU、BGEU、JAL、JALR，共八条指令。

## SPEC

### 条件分支

opcode 为 `0x63`；funct3 的 0、1、4、5、6、7 分别表示 BEQ、BNE、BLT、BGE、BLTU、BGEU。2、3 返回 `YAN_UNSUPPORTED_INSTRUCTION`。

BEQ / BNE 比较相等与不等；BLT / BGE 使用有符号大小比较；BLTU / BGEU 使用无符号大小比较。分支只读取 rs1、rs2，不写通用寄存器。

B 型偏移的位 12、11、10:5、4:1 分别来自指令位 31、7、30:25、11:8，位 0 固定为零。偏移符号扩展后加到当前 PC，范围为 -4096～4094 字节。条件不成立时 PC 增加 4。

### 跳转

JAL 的 opcode 为 `0x6f`。J 型偏移的位 20、19:12、11、10:1 分别来自指令位 31、19:12、20、30:21，位 0 固定为零。偏移符号扩展后加到当前 PC，范围为 -1048576～1048574 字节。

JALR 的 opcode 为 `0x67`，funct3 必须为零。目标为 rs1 加上符号扩展的 12 位立即数，再清除最低位。立即数按字节计算。rs1 与 rd 相同时，使用写回前的 rs1。

两条跳转均将原 PC 加 4 写入 rd；rd 为 x0 时丢弃写入。所有地址运算按 32 位回绕。

### 对齐与错误

当前 IALIGN 为 32。跳转和成立的分支要求目标按四字节对齐，否则返回 `YAN_UNALIGNED`，保留原 PC、通用寄存器和 RAM。未成立的分支不检查目标对齐。

目标是否映射由下一次取指判断；当前控制转移不读取目标地址。自跳转可以正常完成单步。不存在延迟槽，也不自动执行目标指令。

取指失败及非法编码继续返回 Host 状态，并保留 CPU 与 RAM。Guest 异常、CSR、访存、执行循环和设备仍未实现。

### 实现约定与规范依据

使用无符号位运算拼接、符号扩展偏移和计算地址。读取源值、检查编码与对齐后，再提交 PC 和返回地址。

依据 [RISC-V ISA 20260120 / RV32I 2.1](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html) 的 Control Transfer Instructions。本阶段完成后共支持 29 条 RV32I 指令，尚不声明完整 RV32I 兼容性。

## VERIFY

Unity / CTest 覆盖固定机器码、正负偏移及边界、条件真值矩阵、全部寄存器字段、x0、返回地址、目标未对齐与未映射、非法编码和取指失败。B 型遍历全部偏移，J 型覆盖各偏移位和边界，JALR 遍历全部立即数与目标低两位。原有整数计算测试作为回归检查。
