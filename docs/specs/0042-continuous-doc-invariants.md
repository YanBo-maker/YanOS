- **成功标准**：只把 STATUS 增至预算以上或只增规格不补索引时，默认检查失败；合法占位行和字节边界通过；无本地输入不能伪成功；默认执行一次，不追加产品重跑。

## R1：字节预算

读取根目录下 `docs/STATUS.md` 的实际字节，执行0034 AC6.1的预算，包含上限边界。不以字符数替代字节数，不由本检查判断内容、章节或语义是否正确。

- AC1.1：UTF-8多字节构成的16384字节输入通过，16385字节输入报告字节预算失败；控制同时断言退出码和对应失败标记。

## R2：索引数量

只数 `docs/specs/` 一层以 `.md` 结尾的文件，排除 `README.md`。索引数据行首格采用 `| [0001](target) |` 的ASCII四位编号内联链接形态，或裸 `| 0002 |`；target不解析，可为空，不能跨行或包含表格分隔符。表头与分隔行不计。数据行总数应为规格文件数加一。

- AC2.1：合法裸0002计入；README、子目录及非md文件不计入规格文件数。只增一规格不补行、只删一数据行时失败。
- AC2.2：裸0003和只有`[0001]`而无内联目标的首格不计为数据行。数量相同不证明逐文件对应、占位行唯一存在、链接解析或状态正确，不增加这些保证。

## R3：调用与错误

标准库Python独立CLI `--source ROOT`，缺省根目录由脚本位置确定。检查只读，不访问网络、Git历史、模型或产品程序，不递归扫描工作区。

- AC3.1：两项都成立返回0并给出总PASS；违反预算/数量返回1和对应FAIL。有效CLI调用中缺失/不可读本地输入、零规格文件、空白索引或非法UTF-8索引返回2及ERROR，不打印PASS，不返回77。STATUS本身只作字节测量，空文件不因此新增语义错误；CLI语法错误沿argparse的常规处理。
- AC3.2：路径及异常以ASCII安全形式诊断，中文根路径在严格cp1252环境下仍可报告输入错误。检查前后路径、类型和文件字节均不变；控制不能只比较文件名。

- AC4.1：Linux/Windows定向CTest均能找到并运行两个入口及标签；控制使用小型临时树覆盖R1–R3。
- AC4.2：临时总成功、总失败、改写原文件内容的实现分别被指定控制断言拒绝；不新增实际变异组或要求本地完整产品回归。
